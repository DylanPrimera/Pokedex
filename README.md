## Steps to excecute

1. Clone the repository
2. You must have Nest CLI installed
```
pnpm i -g @nestjs/cli
```
3. Run 
``` 
pnpm install
```
4. Setup the DB
```
docker-compose up -d
```
5. Run the API with
```
pnpm start:dev
```

## Stack
* MongoDB
* Nest
* Docker
